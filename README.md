# 里间 Lijian

当前版本：v7.0.5

一款手机优先的私人 HTML 应用室。支持 PWA 安装、密码锁、完整备份、应用数据管理、版本恢复、自由排序、编辑图标、文件夹与标签、收藏和最近打开、批量管理、自动锁定及回收站。v7 新增加密备份、HTML 移动端与离线兼容检查、版本差异查看、空间体检，以及每个应用最多 8 份的数据快照。每个应用的文字图标可以选择透明或色板背景，色板会随浅色与深色外观切换；用户上传的图片保持原样。

应用查看器支持 50%—200% 页面比例、自动适合屏幕宽度、横屏预览、沉浸模式，以及独立的页面滑动锁。显示与滑动设置会按 HTML 应用分别记忆，锁定滑动后仍可正常使用按钮、输入框和页面数据保存。

主题工坊支持导入 `.css`、`.json` 与 `.pvtheme`，标题栏内置“美化教程”，可直接查看 JSON 骨架、常用选择器、安全限制和发布检查。v6 卡片系统开放卡片形状、长宽比例、文字位置、边框、阴影、图片裁切以及三个相互独立的装饰层；主题可以分别关闭或替换装饰线、内框和高光。配色支持保留应用原色、全体统一及按色板循环，`variants` 可以让卡片按照固定周期错落变化。用户上传的图标与文字图标使用同一套主题边框和效果，也可通过 `[data-has-icon="true"]` 单独定制。旧 v1 主题仍会按原样导入。

`.pvtheme` 是 JSON 文件，可包含主题名称、作者、CSS 变量、自定义 CSS、`cards` 卡片配置，以及使用 Data URL 保存的本地图片或字体资源。设置页下载的 v6 模板列出了卡片变量和配色结构；更完整的字段说明见 `THEME-V6.md`。自定义主题不会执行 JavaScript，也不能加载远程资源。

里间会按应用隔离并自动保存表单、滚动位置和页面 localStorage，同时兼容 `localStorage.setItem()` 与 `localStorage.key = value` 两种写法。HTML 也可以调用 `PageVault.saveState(value)` 保存自定义数据，并通过 `PageVault.loadState()` 读取。旧接口名会继续保留，确保升级后原有 HTML 无需修改。完整备份会包含应用、数据快照、主题、设置与版本记录。加密备份使用 PBKDF2-SHA-256 派生密钥与 AES-GCM 加密，密码不会写进文件，也无法代为找回。

应用详情支持导出、导入或清空单个应用的数据；导入和清空前会自动保留快照，也可手动建立、恢复或删除快照。从查看器清空数据时会作废旧运行实例并以空状态重载，避免旧页面再次写回。替换 HTML 时会保留应用资料与运行数据，并自动保存最近 5 个旧版本；保存完成后会同步刷新当前查看器和内存记录，重新打开不会继续读取旧 HTML。旧版本可与当前 HTML 按行对比。查看器内可直接切换最近应用，三点菜单以浮层形式显示，不会卸载当前 HTML。

导入或编辑 HTML 时，里间会检查 viewport、过宽的固定布局、滚动锁、iframe 与远程脚本、样式、图片和媒体资源。检查只给出风险说明，不会擅自改写用户的 HTML。空间体检会显示浏览器估算总占用、里间内容构成和应用体积排行。

PWA 没有地址栏，因此内置了独立救援暗门：重新打开里间后连续点击屏幕左上角 7 次，即可停用自定义主题并恢复默认外观。浏览器模式仍可在网址末尾添加 `?safe=1`。

所有上传的 HTML 与设置都保存在当前浏览器的 IndexedDB / Web Storage 中，静态托管端不会收到这些内容。
