# 页匣 Page Vault

一款手机优先的本地 HTML 应用匣。支持 PWA 安装、密码锁、备份恢复、编辑图标、文件夹与标签、收藏和最近打开、批量管理、自动锁定及回收站。

应用查看器支持 50%—200% 页面比例、自动适合屏幕宽度、横屏预览、沉浸模式，以及独立的页面滑动锁。显示与滑动设置会按 HTML 应用分别记忆，锁定滑动后仍可正常使用按钮、输入框和页面数据保存。

主题工坊支持导入 `.css` 与 `.pvtheme`。`.pvtheme` 是 JSON 文件，可包含主题名称、作者、CSS 变量、自定义 CSS，以及使用 Data URL 保存的本地图片或字体资源。自定义主题不会执行 JavaScript，也不能加载远程资源。

页匣会按应用隔离并自动保存表单、滚动位置和页面 localStorage。HTML 也可以调用 `PageVault.saveState(value)` 保存自定义数据，并通过 `PageVault.loadState()` 读取。备份文件会连同这些应用数据一起导出。

PWA 没有地址栏，因此内置了独立救援暗门：重新打开页匣后连续点击屏幕左上角 7 次，即可停用自定义主题并恢复默认外观。浏览器模式仍可在网址末尾添加 `?safe=1`。

所有上传的 HTML 与设置都保存在当前浏览器的 IndexedDB / Web Storage 中，静态托管端不会收到这些内容。
