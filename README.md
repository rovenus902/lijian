# 页匣 Page Vault

一款手机优先的本地 HTML 应用匣。支持 PWA 安装、密码锁、备份恢复、编辑图标、文件夹与标签、收藏和最近打开、批量管理、自动锁定及回收站。

主题工坊支持导入 `.css` 与 `.pvtheme`。`.pvtheme` 是 JSON 文件，可包含主题名称、作者、CSS 变量、自定义 CSS，以及使用 Data URL 保存的本地图片或字体资源。自定义主题不会执行 JavaScript，也不能加载远程资源；在网址末尾添加 `?safe=1` 可跳过自定义主题进入救援模式。

所有上传的 HTML 与设置都保存在当前浏览器的 IndexedDB / Web Storage 中，静态托管端不会收到这些内容。
