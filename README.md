# 里间 Lijian

一款手机优先的私人 HTML 应用室。支持 PWA 安装、密码锁、完整备份、应用数据管理、版本恢复、自由排序、编辑图标、文件夹与标签、收藏和最近打开、批量管理、自动锁定及回收站。应用名称会在卡片上完整换行显示，不再用省略号截断；HTML 应用图标不再叠加贯穿式装饰线，并对所有自定义主题统一生效。

应用查看器支持 50%—200% 页面比例、自动适合屏幕宽度、横屏预览、沉浸模式，以及独立的页面滑动锁。显示与滑动设置会按 HTML 应用分别记忆，锁定滑动后仍可正常使用按钮、输入框和页面数据保存。

主题工坊支持导入 `.css` 与 `.pvtheme`。`.pvtheme` 是 JSON 文件，可包含主题名称、作者、CSS 变量、自定义 CSS，以及使用 Data URL 保存的本地图片或字体资源。自定义主题不会执行 JavaScript，也不能加载远程资源。

里间会按应用隔离并自动保存表单、滚动位置和页面 localStorage。HTML 也可以调用 `PageVault.saveState(value)` 保存自定义数据，并通过 `PageVault.loadState()` 读取。旧接口名会继续保留，确保升级后原有 HTML 无需修改。完整备份会包含应用、数据、主题、设置与版本记录。

应用详情支持导出、导入或清空单个应用的数据；从查看器清空数据时会作废旧运行实例并以空状态重载，避免旧页面再次写回。替换 HTML 时会保留应用资料与运行数据，并自动保存最近 5 个旧版本。查看器内可直接切换最近应用，三点菜单以浮层形式显示，不会卸载当前 HTML。

PWA 没有地址栏，因此内置了独立救援暗门：重新打开里间后连续点击屏幕左上角 7 次，即可停用自定义主题并恢复默认外观。浏览器模式仍可在网址末尾添加 `?safe=1`。

所有上传的 HTML 与设置都保存在当前浏览器的 IndexedDB / Web Storage 中，静态托管端不会收到这些内容。
